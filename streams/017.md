## Про що поговоримо

За підсумками опитування в Telegram після стріму [#016](/streams/016) спільнота обрала практичне продовження: за ~2 години наживо зібрати невеликий, але повністю робочий вебзастосунок за допомогою AI-агента. Обрали mini X — Twitter-подібний застосунок.

Олег пише код через Claude Code (план Б — Codex), спираючись на короткий бриф/специфікацію, складену разом з Олександром за підходом зі стріму #016. Наприкінці — чесне ретро: що в agentic coding спрацювало, а що ні.

### Що робимо

- Пишемо коротку специфікацію для агента — і одразу перевіряємо, як це працює на практиці
- Реєстрація / логін (спрощений)
- Профіль користувача
- Створення поста
- Стрічка
- Лайк
- Стек: React, NestJS, PostgreSQL
- Динамічно — що встигнемо за 2 години, те й встигнемо
