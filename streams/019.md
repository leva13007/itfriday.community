## Про що поговоримо

### Блок 1 — Звідки взялося 71.5×

- Graphify обіцяє knowledge graph для codebase і гучний claim — **71.5× менше токенів**
- Показуємо розмір хайпу навколо Graphify на YouTube
- Пояснюємо, що ця цифра означає насправді: graph query vs raw corpus на конкретному 52-file workload, а не end-to-end benchmark вирішення coding task
- Головне питання: що від цієї цифри залишиться в реальній роботі з Claude Code

### Блок 2 — Контрольний experiment наживо

- Реальний open-source репозиторій **Excalidraw** і реальний issue **#11846** — "Why it is not possible to have 2 different files opened?"
- Два незалежні клони, однаковий commit, модель, Claude Code версія, prompt
- Два паралельні термінали: Claude Code сам проти Claude Code + Graphify
- Без підказок, без переносу discoveries між runs — тільки те, що Claude знаходить сам
- Окремо заміряємо Graphify cold start — скільки коштує побудувати граф

### Блок 3 — Цифри і висновок

- 🔥 TOKENS — реальна економія і наскільки вона близька до 70×
- ⏱ TIME — скільки часу забрало вирішення задачі в обох runs
- ✅ SOLVED — чи issue реально вирішене й validation пройшла
- Фінальне питання: чи є сенс мені залишати Graphify у реальному Claude Code workflow
