## What we'll cover

You need AI search over your own documents. Do you build a vector index, or give an agent plain grep? We test it live on real data: 25 IT Friday streams, 58 hours of transcripts, speech-recognition errors included.

Three contenders, the same questions, and scoring rules written down in advance:

- **RAG** — embeddings and the top 8 chunks
- **AI agent** — only Grep, Glob and Read, no index
- **Hybrid** — the same agent, plus semantic search through MCP

### Topics

- Building RAG without a vector database: chunking, local embeddings, search
- What a header on each chunk changes: the same search with and without it
- How an agent works without an index, and how many tokens it uses
- Hybrid: connecting RAG to an agent as a tool through a custom MCP server
- Exact facts, rephrased questions, multi-stream questions and counting
- Traps: questions with no answer, and terms that speech recognition got wrong
- The cost of an answer for each contender
- How to choose for your own project
- Your questions from chat, put to the contenders live
