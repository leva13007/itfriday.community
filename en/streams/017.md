## What we'll cover

Following the community's Telegram vote after [#016](/en/streams/016), we're doing the practical follow-up: build a small but fully working web app live in ~2 hours with an AI agent. The community picked mini X — a small Twitter-like app.

Oleh writes the code with Claude Code (Codex as fallback), working from a short brief/spec drafted together with Oleksandr using the approach from #016. We close with an honest retro on what worked and what didn't in agentic coding.

### What we're building

- Writing a short spec for the agent — and immediately checking how it holds up in practice
- Sign-up / login (simplified)
- User profile
- Post creation
- Feed
- Like
- Stack: React, NestJS, PostgreSQL
- Built dynamically — whatever we get done in 2 hours
